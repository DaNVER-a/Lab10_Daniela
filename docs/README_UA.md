# Лабораторна робота №10 — ТПП

Студент: **Вергуненко Даніела Сергіївна**. Група: ФІТ-3-17.

Тема: застосування поведінкових патернів проєктування.
Предметна область: **Робота кол-центру**.

Ця робота є окремою індивідуальною реалізацією та продовжує функціональність лабораторної №8.
Збережено моделі предметної області, зв'язок 1:N, SQLite, `sqlite_orm`, Repository та C++20.

## Реалізовано

- **State**: Registered → Accepted → Completed; окремо Cancelled. Недопустимий перехід відхиляється; історія зберігається в таблиці SQLite транзакційно.
- **Strategy**: три альтернативні способи обчислення показника: максимальне нормоване значення, зважена сума, нормована зважена сума. Вхідні параметри: важливість, терміновість, час очікування.
- **Observer**: події реєстрації та зміни стану, два підписники — журнал і статистика; підписка та відписка під час виконання.
- **Command** (додатковий GoF-патерн): об'єкти команд зберігають посилання на сервіс, ідентифікатор та дію; Invoker виконує їх послідовно.
- **Тести**: перевірка логіки та окремі інтеграційні перевірки SQLite/ORM і відкату транзакції.

## Підготовка Visual Studio

Розпакуйте архів як папку `Lab10_Daniela` у `C:\Users\stsdu\source\repos`.
Відкрийте Visual Studio → **File → Open → Folder** → `Lab10_Daniela`.
Оберіть конфігурацію **default** і **Build → Build All**.
При першому налаштуванні Visual Studio/vcpkg встановить `sqlite3` та `sqlite-orm` з `vcpkg.json`.

Якщо ваша Visual Studio встановлена не в `C:/Program Files/Microsoft Visual Studio/18/Insiders`, змініть `CMAKE_TOOLCHAIN_FILE` у `CMakePresets.json` на фактичне розташування vcpkg.

## Запуск

Запустіть через список цілей Visual Studio (Ctrl+F5):

1. `Lab10_CallCenter.exe` — старі перевірки лабораторної №8 і нова демонстрація чотирьох патернів.
2. `Lab10_CallCenter_Tests.exe` — модульні тести станів, стратегій, подій і команд.
3. `Lab10_CallCenter_DBTests.exe` — інтеграційні перевірки історії, транзакцій, відкату та станів у SQLite.

Очікувані ключові ознаки: `Patterns demo: PASS`, `Pattern unit tests: PASS`, `SQLite/ORM integration tests: PASS`.

Тестові БД створюються у робочій папці програми; файли `*.db` виключені з Git через `.gitignore`.
